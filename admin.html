🔑 Netlify Token কিভাবে পাবেন (একবারই করতে হবে)

Step 1: app.netlify.com এ যান → Sign Up / Login করুন (GitHub দিয়ে করলে সহজ)

Step 2: Login এর পর উপরে ডানে আপনার Avatar/Profile ক্লিক করুন

Step 3: "User Settings" এ ক্লিক করুন

Step 4: বামে "Applications" ক্লিক করুন

Step 5: "Personal access tokens" সেকশনে "New access token" এ ক্লিক করুন

Step 6: Description এ যেকোনো নাম দিন (যেমন: "gift-creator") → "Generate token" ক্লিক করুন

Step 7: যে Token দেখাবে সেটা কপি করে নিচে পেস্ট করুন

⚠️ Token একবারই দেখাবে, তাই কপি করে রাখুন! এটা আপনার ব্রাউজারে সেভ থাকবে।
